# 相机、打印物与坐标系记录

> 棋盘格已按 100% 打印并用后置摄像头标定，分辨率 1280×720，参数在 `data/calib/camera.json`。打印尺寸与标称值一致：黑框 100 mm，方格 20 mm。

## 1. 摄像头

| 项目 | 记录 |
| --- | --- |
| 型号 / 类型（内置、USB UVC、模组） | 红米 24122RKC7C 后置摄像头，USB 调试后由 scrcpy 取画面，不是电脑内置摄像头 |
| 设备节点 | ADB 序列号 `492cd76d`，scrcpy 相机编号 0 |
| 标定与运行分辨率 | 1280×720 |
| 对焦方式 | 手机自动对焦，标定过程中没有锁定 |
| 曝光、白平衡 | 未固定 |

Ubuntu 下可用 `v4l-utils` 查看和固定参数（仅为参考命令，控件名称因设备而异）：

```bash
v4l2-ctl --list-devices
v4l2-ctl -d /dev/video0 --list-formats-ext
v4l2-ctl -d /dev/video0 --list-ctrls
v4l2-ctl -d /dev/video0 -c focus_automatic_continuous=0   # 旧驱动可能叫 focus_auto
```

标定后不要再改变焦距、分辨率或裁剪方式，否则需要重新标定。

## 2. 打印物实测

打印时选择「实际大小 / 100%」，不要勾选「适合页面」。打印后用尺子测量，程序参数使用实测值。

| 项目 | 标称值 | 实测值 | 程序参数 |
| --- | --- | --- | --- |
| tag36h11 ID0 黑色外框外边长 | 100.0 mm | 100.0 mm，与标称值一致 | `--tag-size 0.100` |
| 棋盘格单个方格边长 | 20.0 mm | 20.0 mm，与标称值一致 | `--square 0.020` |
| 棋盘格规格 | 10x7 方格 / 9x6 内角点 | — | `--cols 9 --rows 6`（默认值） |

`tag_size` 指检测出的四个角点之间的边长，即黑色外框的外边长（8 格中的 8 格），不包括外圈白边，也不是纸张宽度：

```text
 ┌──────────────────────────┐  ← 纸张 / 白色留边（不计入）
 │   ┌──────────────────┐   │
 │   │■■■■■■■■■■■■■■■■■■│   │  ← 黑色外框外边：tag_size
 │   │■  6x6 数据位     ■│   │
 │   │■■■■■■■■■■■■■■■■■■│   │
 │   └──────────────────┘   │
 └──────────────────────────┘
```

## 3. 坐标系

相机光学坐标系（本工程统一使用）：原点在光心，X 向图像右，Y 向图像下，Z 沿光轴向前。

Tag 坐标系（采用 AprilTag 官方定义，pupil-apriltags 直接返回）：原点在 Tag 中心，Tag 正对相机且图案为官方朝向时 X 向右、Y 向下、Z 指向 Tag 内部（远离相机）。

```text
        相机                       Tag（正对相机，官方朝向）
      +Z（向前）
        ↑                          3 ────────── 2
        │                          │     -Y     │
        o───→ +X                   │  -X  o  +X │     +Z 垂直纸面向里
        │                          │     +Y     │
        ↓ +Y                       0 ────────── 1
```

角点编号 0–3 是 pupil-apriltags 返回的顺序，对应 Tag 坐标 `(-s/2, +s/2)`、`(+s/2, +s/2)`、`(+s/2, -s/2)`、`(-s/2, -s/2)`（s 为 tag_size，与 apriltag 源码 `apriltag_pose.c` 中的物点一致），程序在画面上标出编号，不调换顺序。

变换方向：`p_camera = R × p_tag + t`。t 是 Tag 中心在相机坐标系中的位置（米）；`t[2]` 是 Z 深度，`‖t‖ = sqrt(x²+y²+z²)` 是直线距离，两者不同。
